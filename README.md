# Catálogo de Produtos

Projeto desenvolvido como atividade acadêmica utilizando **React Native, Expo e FlatList**.

## Sobre o projeto

O aplicativo apresenta um catálogo simples de produtos, exibindo nome, preço e categoria de cada item de forma organizada.

## Tecnologias utilizadas

- React Native
- Expo
- JavaScript
- FlatList

## Funcionalidades

- Listagem de produtos.
- Exibição de nomes e preços.
- Organização visual em cartões.
- Formatação de preços em reais (R$).

## Como executar

```bash
npx expo start
```
